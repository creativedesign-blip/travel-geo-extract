## 命名規範

- **國家**：ISO 3166-1 alpha-2，例 `TW / JP / KR / TH / VN / PH / ID / CN`
- **地區**：`<國家碼>-<地區3碼>`，地區3碼為英文首字母縮寫，例 `JP-KTO`（Kanto）、`CN-EAS`（East）
- **城市**：`<地區碼>-<城市3碼>` 或 `<國家碼>-<城市3碼>`（無地區層），城市3碼盡量取 IATA / 拼音首字母

## 異名/陷阱

| 詞 | 警告 |
|---|---|
| 高山 | 可能是 JP-CBU-TKY (飛驒高山) 或一般詞「高山火車」「高山症」 |
| 東北 | 可能是 JP-THK 或 CN-NEA |
| 中國 | 可能是 CN（中華人民共和國）或 JP-CGK（日本中國地方）|
| 桃園 | 可能是 TW-TYU 城市或單指桃園機場（landmark）→ 走 transit |
| 倫敦 | 業務範圍外 → SKIP，但可能誤匹配文案中「倫敦塔」「倫敦眼」 |
| 威尼斯 | 業務範圍外，且常作比喻「東方威尼斯」→ SKIP |
